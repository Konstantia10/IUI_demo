A Terrible Day at the Office — 2D prototype

Files:
- index.html
- styles.css
- app.js
- assets/office-poster.jpg

How to run:
1. Open the folder in Visual Studio Code.
2. Open index.html.
3. Use the Live Server extension (right click -> Open with Live Server), or open index.html directly in a browser.
4. Test the hotspots, checklist, assistant, and design-intent selector.

Notes:
- This version uses a scripted JavaScript agent, not a real LLM API yet.
- The next step can replace agent() with an API-backed LLM while keeping the rest of the interface and tools.
