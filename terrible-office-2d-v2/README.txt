A TERRIBLE DAY AT THE OFFICE — 2D INTERACTIVE V2

Files:
- index.html
- styles.css
- app.js
- assets/office-poster.jpg

Run locally:
1. Open this folder in VS Code.
2. Open index.html with Live Server (recommended), or open index.html directly.

New interactions:
- Live current-time overlay.
- Click phone, monitor, coffee, to-do and document hotspots.
- Drag loose paper to the bin on desktop.
- On touch/mobile: tap the paper, then tap the bin.
- Interactive task checklist.
- Undo paper disposal.
- Assistant quick actions and simple text interpreter.
- Supportive, persuasive and manipulative design-intent modes.
- Each design-intent mode changes wording AND visual/choice architecture.

This version intentionally uses a scripted JavaScript agent. No API key or LLM is required. A real LLM can be connected later without changing the core UI interactions.
